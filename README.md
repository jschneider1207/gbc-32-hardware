# Game Boy Color 32: hardware

Custom handheld PCB for the [Game Boy Color 32](../gbc-32) emulator,
covering stages 3 (prototype board) and 4 (refined board) of that project.

This repo is kept separate from the firmware repo on purpose. Hardware
design is human-led and uses agents as discussion and validation partners
(see `AGENTS.md`). The firmware repo is developed autonomously by agents.

- Requirements: `docs/requirements.md`
- What the firmware needs from the board: `docs/firmware-interface.md`
- Decisions: `docs/decisions/`
- Calculations: `calc/`
- Datasheets: `datasheets/README.md` (PDFs are kept locally, not in git)
